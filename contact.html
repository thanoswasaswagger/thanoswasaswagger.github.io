Contact ASHBIZCON

For product support, purchase questions, refunds, security reports, or privacy questions, use the public support tracker below.

Public support

Open a support request in the ASHBIZCON public GitHub issue tracker. Please include the product name, a clear description of the problem, and non-sensitive screenshots where useful.

Security reports

For suspected security issues, avoid posting secrets, credentials, private customer data, or exploit details publicly. Use the repository's published security guidance and contact channel appropriate for the affected product.

Purchase and refund support

For payment or refund questions, include the order or transaction reference if available, but never send full card details or passwords.

A monitored business support email should be added here before live checkout launch if Paddle or a marketplace requires an email contact. We will not invent or publish a private email address without authorization.
